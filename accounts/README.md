# Accounts

One folder per account or prospect, slug-named. Start from `_template/`.

```
accounts/<slug>/
  profile.md      — who they are, segment, regulator, size, systems, people, decision map
  engagement.md   — what is happening now: history, current state, next action, risks
  deliverables/   — anything produced for them (or a pointer to it in ofs-marketing)
```

**Rule:** the account folder is the truth about that account. If you learn it, write it here.
Cross-cutting lessons also go to `memory/facts.md`.
