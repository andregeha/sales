# OFS Sales

The sales workspace of **Omega Financial Solutions** — makers of **Gaia**, a front-to-back
portfolio and fund management platform.

This repo is run as an **agent team**: an orchestrator plus specialized agents for research,
solution engineering, deal strategy, writing and tooling. It is also the **system of record** for
what we know, what we decided, and every account we are working.

## The one rule that matters most
**Ground every client-facing claim in `knowledge/`, and never mix what we sell today with what a
client currently runs.** Everything else in `CLAUDE.md` follows from that.
