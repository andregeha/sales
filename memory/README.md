# Memory — the durable brain

Everything we learn and decide lands here, so no knowledge dies with a conversation.

| File | What goes in it | When |
|---|---|---|
| `facts.md` | Durable, non-obvious facts: people, entities, constraints, gotchas, how things really work. | The moment a fact is established. |
| `decisions.md` | Decisions and their reasoning, dated. Including decisions *not* to do something. | Every decision that would be expensive to re-litigate. |
| `open-questions.md` | Anything unknown, unverified or needing Andre's approval. Owner + status. | The moment a gap appears — never leave it in your head. |
| `changelog.md` | What changed in this workspace, session by session. | End of every working session. |

## Rules
1. **A fact without a source is a rumour.** Cite where it came from and how confident we are.
2. **Never overwrite history** — supersede with a date and say what changed.
3. Account-specific knowledge lives in `accounts/<slug>/`, not here. This is cross-cutting memory.
4. If a fact contradicts something in `knowledge/`, fix `knowledge/` and note it in `changelog.md`.
